Remarks

Supplied as the second constructor parameter, ahead of the optional logger. When the whole options object is null, or an individual property is left unset, the documented defaults below apply — defaults live on the property initializers here rather than in constructor bodies, so no constructor can accidentally diverge from them.

This record deliberately carries no Encoding property. Byte encoding is performed by the StreamWriter supplied to the constructor, whose Encoding is authoritative; the former Encoding property never influenced it and is obsolete. To write a non-default encoding, construct the StreamWriter with the encoding you want.

The inherited Wolfgang.Etl.Abstractions.LoaderOptions.ErrorPolicy is not consulted by CsvLoader<TRecord>. CsvHelper writes a record's fields into the output one at a time, so a record that fails partway through cannot be withdrawn: skipping it would leave a half-written row in the file. A failure while writing a record therefore always propagates out of LoadAsync. To drop records before they reach the writer, use Validators with OnValidationFailure set to Skip.

IsDryRun

Gets a value indicating whether the load runs as a dry run. When true, the loader enumerates the source, honours Wolfgang.Etl.Abstractions.LoaderOptions.SkipItemCount / Wolfgang.Etl.Abstractions.LoaderOptions.MaximumItemCount, increments progress counters, fires progress reports and logs as a real load would — but writes nothing to the underlying writer (neither the header nor any records), so CurrentLineNumber stays 0. Use it to validate a pipeline against real data without producing output. Defaults to false.
