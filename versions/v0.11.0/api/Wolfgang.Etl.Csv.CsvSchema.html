A record type's CSV column mapping as a first-class, introspectable object — the code-first counterpart of CsvColumnAttribute / CsvIgnoreAttribute decorations. Produced by Build(), or reified from a type's attributes by For<T>(), and applied through Schema / Schema.

Remarks

A schema is bound to the RecordType it was built for: an extractor or loader for a different record type rejects it at construction. It is applied through the same internal column-map path as ColumnMaps (with which it is mutually exclusive), so a code-built schema behaves identically to the equivalent attributed record.

Columns is read-only and is the identity key for the compiled map's cache, so reuse one CsvSchema instance across runs rather than rebuilding it per call.

For<T>()

Reifies the attribute-resolved mapping of T as a schema: every public instance property becomes a column, honouring CsvColumnAttribute and omitting members marked CsvIgnoreAttribute. Undecorated properties bind by their own name, exactly as the attribute path does.
