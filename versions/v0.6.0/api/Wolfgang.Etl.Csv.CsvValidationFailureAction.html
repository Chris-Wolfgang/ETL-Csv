Enum CsvValidationFailureAction

Namespace
Wolfgang.Etl.Csv
Assembly
Wolfgang.Etl.Csv.dll

Chooses what a CsvExtractor<TRecord> (or CsvLoader<TRecord>) does with a record that fails one or more CsvValidator<T>s. In every case the invalid record is counted (CurrentInvalidItemCount) and the InvalidRecordHandler, if any, is invoked first.

public enum CsvValidationFailureAction

Fields

Continue = 0

Yield / write the record anyway — the caller decides what to do with it.

Skip = 1

Drop the record: it is neither yielded nor written, and it does not count as extracted / loaded.

Stop = 2

Raise a CsvValidationException and end the operation.
