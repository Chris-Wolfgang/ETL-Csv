Examples

using var reader = new StreamReader("people.csv");
var extractor = new CsvExtractor<Person>(reader);
await foreach (var person in extractor.ExtractAsync(cancellationToken))
{
    Console.WriteLine(person.Name);
}

BadDataFound

Gets or sets a callback invoked when the underlying parser detects bad data. Use this to log, count, or quarantine bad records as they're encountered.

[Obsolete("Deprecated in favor of the unified ErrorPolicy for failure handling. This observation callback still fires (and CurrentBadDataCount still counts) when the parser reports malformed data; bad data remains tolerated, while parse/type-conversion failures are governed by ErrorPolicy.")]
public Action<CsvBadDataInfo>? BadDataFound { get; set; }

Property Value

Action<CsvBadDataInfo>

Remarks

When null (the default), bad data is silently counted via CurrentBadDataCount but not logged — the library deliberately does not write CSV record contents to your logger, since CSV records frequently contain PII. Wire this to your logger if you want diagnostic output, e.g.:

extractor.BadDataFound = info => _logger.LogDebug("Bad CSV data on line {Line}: {Field}", info.LineNumber, info.Field);

Extraction always continues after a bad-data event. To abort, throw from the callback or trip the CancellationToken passed to ExtractAsync.

Encoding

Property Value

Encoding

Remarks

This value is informational only — it is passed to CsvHelper's CsvConfiguration.Encoding but does not control how bytes are decoded into characters. Decoding happens inside the StreamReader supplied to the constructor, and that reader's CurrentEncoding is authoritative. To read a non-default encoding, construct the StreamReader with the encoding you want and ignore this property.

InitialRecordIndex

Gets or sets the 1-based index of the first line the parser will consume from the source. Lines before this index are read and discarded.

public int InitialRecordIndex { get; set; }

Property Value

int

Remarks

The line at InitialRecordIndex is treated as the first line read, not necessarily the first data row. When HasHeaderRecord is true, it becomes the header row (column names); when HasHeaderRecord is false, it becomes the first data row. Set this to skip metadata or banner lines that precede the header / data section.

Action<CsvReadingExceptionInfo>

Remarks

When null (the default), the exception is not logged by the library. The exception always propagates out of ExtractAsync regardless of the callback — this hook is for observation only. Wrap your await foreach in try / catch if you want to swallow individual row failures.

    _logger.LogDebug(info.Exception, "Parse error on line {Line} column {Col}: {Value}",
        info.LineNumber, info.ColumnNumber, info.ColumnValue);
