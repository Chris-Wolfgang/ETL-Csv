Encoding

Gets or sets the encoding forwarded to CsvHelper's writer configuration.

public Encoding Encoding { get; set; }

Property Value

Encoding

Remarks

This value is informational only — it is passed to CsvHelper's CsvConfiguration.Encoding but does not control how characters are encoded into bytes on the output stream. Byte encoding is performed by the StreamWriter supplied to the constructor, and that writer's Encoding is authoritative. To write a non-default encoding, construct the StreamWriter with the encoding you want and ignore this property.
