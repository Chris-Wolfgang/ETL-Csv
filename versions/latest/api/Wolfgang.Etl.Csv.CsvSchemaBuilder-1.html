Remarks

Properties are selected with an Expression<TDelegate> (x => x.Name), so the mapping is compile-time checked and survives a rename. Build() produces a CsvSchema whose columns are the same CsvColumnMap leaf type the attribute path resolves to, so a code-built schema is behaviorally identical to the equivalent [CsvColumn]-decorated layout. Apply it through Schema / Schema; leaving that unset keeps today's attribute behavior. 

var schema = new CsvSchemaBuilder<Order>()
    .Column(o => o.Id,     name: "order_id")
    .Column(o => o.Placed, name: "placed_at", format: "yyyy-MM-dd")
    .Column(o => o.Total,  name: "amount",    format: "0.00")
    .Build();

var extractor = new CsvExtractor<Order>(reader, new CsvExtractorOptions<Order> { Schema = schema });

public CsvSchemaBuilder<T> Column<TProperty>(Expression<Func<T, TProperty>> selector, string? name = null, int index = -1, string? format = null, bool optional = false, string? @default = null)

Parameters

selector Expression<Func<T, TProperty>>

A property selector, e.g. x => x.Name. Must be a direct access of a public property of T (an inherited property is fine) — not a field, method, nested/chained member, or computed expression.

name string

The CSV column name to bind to. Must not be blank, and must not be combined with a non-negative index (a column binds by name or by index, not both). Leave it null to bind by the property's own name.

index int

The 0-based column index; -1 (default) binds by name only.

format string

Parse/format string (e.g. "yyyy-MM-dd").

optional bool

When true, a missing column does not fail the read.

default string

Default value used when the column is absent or empty during reading.

Returns

CsvSchemaBuilder<T>
