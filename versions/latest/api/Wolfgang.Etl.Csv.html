Syntactic sugar for the resumable-extraction pattern: atomically persist and read back a record counter, and resume a CsvExtractor<TRecord> from it via SkipRecordCount.

Runtime descriptor for a single property-to-column mapping. The parser-agnostic equivalent of CsvColumnAttribute for cases where the layout isn't known until runtime (for example, layout selected from configuration or a database).

CsvReadingExceptionInfo

Describes a recoverable parse exception encountered while reading a CSV stream. Surfaced to the caller via ReadingExceptionOccurred so logging, metrics, or quarantine logic can be plugged in without the library making logging decisions on the caller's behalf.

CsvShouldQuoteContext

Provides per-field context to a ShouldQuote callback while writing a CSV stream.

EtlPipelineCsvExtensions

Class-named CSV source factories and sink terminators for the fluent Wolfgang.Etl.Abstractions.EtlPipeline chain. Source factories hang off Wolfgang.Etl.Abstractions.EtlPipeline so a pipeline reads EtlPipeline.Create().CsvExtractor<Order>("orders.csv"); sink terminators hang off Wolfgang.Etl.Abstractions.IEtlPipeline<T> so it ends … .CsvLoader<Order>("out.csv").RunAsync().

Interfaces

ICsvExtractorBuilder<T>

Fluent builder for a CsvExtractor<TRecord> hung off the generic Wolfgang.Etl.Abstractions.EtlPipeline chain. Extends Wolfgang.Etl.Abstractions.IEtlPipeline<T>, so a consumer transitions from configuring the extractor to appending pipeline operators simply by calling one — no explicit Build() step. The first pipeline operator (for example Where, Select, or a Wolfgang.Etl.Abstractions.IEtlPipeline<T>.Through<TOut>(Wolfgang.Etl.Abstractions.ITransformAsync<T, TOut>) stage) materializes the extractor and the configuration setters fall off the surface.

ICsvLoaderBuilder<T>

Fluent builder for a CsvLoader<TRecord> that terminates the generic Wolfgang.Etl.Abstractions.EtlPipeline chain. Extends Wolfgang.Etl.Abstractions.IEtlPipelineSink, so the pipeline is runnable as soon as the terminator is called; the fluent setters simply refine the loader before RunAsync(IProgress<EtlPipelineProgress>, CancellationToken) materializes and runs it.
