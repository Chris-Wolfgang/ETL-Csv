Class-named CSV source factories and sink terminators for the fluent Wolfgang.Etl.Abstractions.EtlPipeline chain. Source factories hang off Wolfgang.Etl.Abstractions.EtlPipeline so a pipeline reads EtlPipeline.Create().CsvExtractor<Order>("orders.csv"); sink terminators hang off Wolfgang.Etl.Abstractions.IEtlPipeline<T> so it ends … .CsvLoader<Order>("out.csv").RunAsync().

Remarks

Path-based factories own the file stream they open and dispose it after the run (success or failure). Factories that accept a caller-supplied StreamReader, StreamWriter, or a pre-built extractor/loader do not dispose it — the caller owns the lifecycle. The fluent configuration setters returned by these factories map 1:1 to the underlying CsvExtractor<T> / CsvLoader<T> properties.
