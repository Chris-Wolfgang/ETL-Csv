Fluent builder for a CsvLoader<TRecord> that terminates the generic Wolfgang.Etl.Abstractions.EtlPipeline chain. Extends Wolfgang.Etl.Abstractions.IEtlPipelineSink, so the pipeline is runnable as soon as the terminator is called; the fluent setters simply refine the loader before RunAsync(IProgress<EtlPipelineProgress>, CancellationToken) materializes and runs it.

public interface ICsvLoaderBuilder<T> : IEtlPipelineSink where T : notnull

Remarks

Each setter maps 1:1 to a public property on CsvLoader<TRecord>; no new configuration surface is introduced. Stream ownership is decided by the terminator overload, not a setter: a path-based sink owns and disposes the file it opens (on success and failure), while a caller-supplied StreamWriter is left open for the caller.
