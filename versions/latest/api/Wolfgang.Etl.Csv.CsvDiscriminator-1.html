Describes how a single CSV file mixes multiple record shapes, keyed by a discriminator column, so a CsvExtractor<TRecord> binds each row to the right concrete type and a CsvLoader<TRecord> writes each record's type and columns. Build one with CsvDiscriminatorBuilder<TBase> — that path is trim/AOT-safe. Constructing it directly from a Mapping dictionary is supported but reflects over the mapped types at run time.

public sealed class CsvDiscriminator<TBase> where TBase : notnull
