Fluent, trim/AOT-safe builder for a CsvDiscriminator<TBase>. Each Map<T>(string, IReadOnlyList<CsvColumnMap>?) call names a concrete type generically, so the mapping and its per-type CsvColumnMaps are resolved with the property metadata trimming/AOT needs preserved.
