Remarks

Supplied as the second constructor parameter, ahead of the optional logger. When the whole options object is null, or an individual property is left unset, the documented defaults below apply — defaults live on the property initializers here rather than in constructor bodies, so no constructor can accidentally diverge from them.

This record deliberately carries no Encoding property. Decoding is performed by the StreamReader supplied to the constructor, whose CurrentEncoding is authoritative; the former Encoding property never influenced it and is obsolete. To read a non-default encoding, construct the StreamReader with the encoding you want.

BadDataFound and ReadingExceptionOccurred are intentionally absent: both are already obsolete on CsvExtractor<TRecord>, superseded by the unified error policy. Carrying them onto a new options record would reintroduce deprecated surface.
